# OOM 内存压力与预测式分级冻结实验

本项目在 Ubuntu VM 上比较同一组四任务的串行、无干预并发和预测式分级冻结。前台是受保护的 Krita，三个后台分别是栅格条带校正、内存列式表转换和批量数组评分。

## 当前策略

- 以 Krita 首页就绪为 T0。两个并发模式采用同一组后台计划偏移，数组 +64 秒、栅格 +72 秒、列式表 +73 秒。后台到点运行，首批完成后具备冻结资格。
- 每轮从现场 `MemAvailable` 扣除 Krita 剩余历史峰值预留和未来 2.5 秒的后台预计增长。预计最低余量低于 500 MiB 时试算冻结。考虑恢复候选后的预计最低余量须严格高于 756 MiB，并连续达标至少 0.5 秒。
- 冻结暂停任务执行，已驻留的内存继续计账。实验结果记录实际启动、内核冻融确认、内存曲线和输出校验。
