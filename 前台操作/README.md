# 前台操作

Krita 自动化有两个入口，均只运行前台。`krita_auto.py` 直接在桌面执行打开文档、缩放、高压实例切换及中压尾段。`collect_krita.py collect` 在独立的用户 systemd cgroup 中调用同一脚本，同时保存可用于构建参考曲线的采样和验证证据。[运行命令](前台操作自动化脚本采集/README.md) · [ORA 素材](素材/README.md)

用 `prepare_handoff_config.py` 生成适配当前 VM 的配置与清单。高压文档确认打开后采样 12 秒，首实例确认退出后由第二实例执行 30 秒中压浏览。导入、关闭和实例切换另外耗时，实测阶段边界以事件日志为准。[场景时序](前台操作自动化脚本采集/TIMED_CAPTURE.md)

只交付 GUI 自动化时，提供本目录的源码和 ORA 压缩包即可按前台指南部署。若还要生成通过验收的参考曲线，采集器需要已提交的 Git 源码和系统证据。四任务跑法见 [复现实验](../复现实验.md)。
